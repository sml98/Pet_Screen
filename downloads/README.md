# APK pronto para instalar

[Baixar Gato-de-Tela.apk](https://github.com/sml98/Pet_Screen/raw/refs/heads/main/downloads/Gato-de-Tela.apk)

Android 8 ou superior. APK release assinado com chave própria do projeto, sem permissão de internet. Veja `SHA256.txt` para verificar o arquivo. Permita instalar por essa fonte e depois ative “Aparecer sobre outros apps” na tela do app.

O arquivo é mantido aqui para permitir download público direto mesmo quando a integração não consegue enviar anexos ao endpoint de Releases. A página da versão aponta para esse APK. Não há keystore ou senha no repositório.
